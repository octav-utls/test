# OCTAV UTLS website template

A simple static website template inspired by the organization of the A-RIP/S-RIP publications site: header, left navigation, project sections, publications, meetings, resources, contacts, and footer.

## Use

1. Edit `index.html` to replace placeholder text, links, names, publications, and contact details.
2. Edit `styles.css` to adjust colors, spacing, and typography.
3. Publish with GitHub Pages by placing these files in a repository and enabling Pages.
